常见问题

还有疑问？

和微信文件助手有什么区别？ +
微信文件助手 7 天过期，文件存手机上占空间，找起来还得翻聊天记录。拾忆的文件存在你自己电脑上，永久不过期，还能用自然语言搜索、OCR 识别图片内容。
和 Siri / 小爱同学有什么区别？ +
Siri / 小爱是语音助手，只能回答简单问题。拾忆能管文件、管待办、记琐事，支持本地 OCR 识图、文件搜索，多人共享同一个知识库。数据不离开你的电脑。
支持哪些 AI 模型？ +
任何 OpenAI 兼容 API 都支持。包括 DeepSeek、Qwen (通义千问)、OpenAI、智谱、Moonshot 等。你也可以用本地模型（如 Ollama），只要它暴露兼容接口。API Key 只存本地，请求直连模型厂商。
数据安全吗？别人能看到我的文件吗？ +
所有数据存在你电脑本地的 SQLite 数据库，OCR 识别也在本地完成。API Key 只存本地配置文件。共享成员通过角色权限控制访问范围。
可以部署在 NAS 或旧电脑上吗？ +
可以。装在群晖 / 威联通等 NAS 上天然 24 小时在线，NAS 上的文件直接就是知识库。也可以装在闲置旧电脑或迷你主机上，设置开机自启。基于 Tauri 2 构建，资源占用很低。局域网内任何设备都能访问。
支持哪些系统？ +
macOS (Apple Silicon M1–M4 + Intel) 和 Windows 10/11。基于 Tauri 2 (Rust + WebView) 构建，比 Electron 更轻量，安装包更小，内存占用更低。
