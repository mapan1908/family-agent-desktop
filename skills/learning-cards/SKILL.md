# 学习卡片生成

## 适用场景
当用户发送 PDF、EPUB、DOCX 等文档，并表示「做成学习卡片」「提取知识点」「给孩子做学习资料」时使用。

## 执行步骤

1. 使用 `read_file` 工具读取文档内容
2. 按章节 / 段落拆分
3. 每个章节提取 3-5 个核心知识点
4. 按以下模板生成学习卡片：

```
## 知识点名称
简短解释（适合 6-12 岁孩子阅读）
```

5. 所有卡片汇总后，使用 `save_file` 存到 `/data/files/学习卡片/{书名}/`
6. 文件命名：`{序号}-{知识点}.md`
7. 回复用户：「已生成 XX 张学习卡片，保存在 学习卡片/{书名}/」

## 质量控制
- 每张卡片控制在 150 字以内
- 避免专业术语，或用括号解释
- 删去作者序言、目录、引用等非正文内容
- 如果有配图，保留图片 URL 并标注
