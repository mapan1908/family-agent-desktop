# 月度记账报表

## 适用场景
用户要求「生成记账报表」「本月花了多少」「财务总结」时使用。

## 执行步骤
1. 使用 `db_query` 查询本月开销记录
2. 按类别汇总（餐饮、交通、购物、娱乐等）
3. 对比上月数据，标注增减
4. 生成 Markdown 格式报表
5. 回复用户（文字摘要），完整报表存到 `/data/files/记账报表/{月份}.md`

## 报表模板
```
# {月份} 家庭开销报告
总支出：¥
比上月：+/- ¥

| 类别 | 金额 | 占比 | 环比 |
|------|------|------|------|
| 餐饮 |      |      |      |
| 交通 |      |      |      |
...
```
